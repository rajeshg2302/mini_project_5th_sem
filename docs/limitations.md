# PhishGuard Project Limitations

## Explicit Scientific & Operational Disclaimers

1. **Synthetic Dataset Baseline:** Initial development and model benchmarks are evaluated on synthetic training data. High metrics on synthetic data should not be interpreted as real-world accuracy guarantees.
2. **Static URL String Analysis Only:** PhishGuard analyzes website address strings. It does **not** download webpage HTML, analyze DOM elements, inspect SSL certificate authority trees, or perform visual computer vision rendering.
3. **Probabilistic ML Inference:** Predictions and risk scores reflect statistical probabilities generated by machine learning models and are not absolute guarantees of website safety.
4. **False Positives & False Negatives:** Complex evasion techniques (such as fast-flux DNS, compromised legitimate subdomains, or zero-day obfuscation) may result in false negatives. Conversely, unusual legitimate URL paths may trigger false positives.
5. **No Domain Reputation API Dependency:** PhishGuard operates 100% locally and does not query external WHOIS, Google Safe Browsing, or commercial threat intelligence APIs.
6. **Educational & Research Scope:** Built for a 5th-Semester AIML Mini Project demonstrator to showcase end-to-end ML engineering, explainable AI, and full-stack cybersecurity principles.
